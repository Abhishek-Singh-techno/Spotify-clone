# 🎧 Spotify Clone | Pure HTML & CSS

A pixel-conscious recreation of the Spotify web player UI, built using **only HTML5 and CSS3**: no JavaScript, no frameworks, no libraries.

**[🔗 Live Demo](https://abhishek-singh-techno.github.io/Spotify-clone/)**


## 💡 Why I Built This

I wanted to prove that a clean, professional-looking UI doesn't need a framework. This project is my deep dive into **layout systems, responsive design, and CSS craftsmanship**. It shows how far you can go with strong fundamentals.

## ✨ Features

- 🎨 Faithful Spotify-style dark theme with a green accent palette
- 📐 Layout built with **CSS Flexbox & Grid** (sidebar, main content, now-playing bar)
- 🃏 Reusable card components for playlists, albums and artists
- ✨ Smooth hover effects and transitions (CSS only)
- 🔍 Semantic HTML for better accessibility and SEO
- 🧹 Clean, well-organized, commented code

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| **HTML5** | Semantic structure |
| **CSS3** | Flexbox, Grid, variables, transitions |

## 🧠 What I Learned

- Structuring complex layouts with Flexbox and Grid
- Using **CSS custom properties** for maintainable theming
- Creating polished interactions with CSS transitions
- Organizing a project so the code is easy to read and scale
